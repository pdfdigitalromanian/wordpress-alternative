# apps/web

CMS admin, visual editor, and public SSR renderer. React Router (Framework
Mode, `ssr: true`) + Vite, deployed to Vercel via `@vercel/react-router`.

See the repo root `docs/architecture.md` and `docs/setup.md`.

```bash
pnpm dev       # http://localhost:5173
pnpm build
pnpm typecheck
```
